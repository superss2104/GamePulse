# `web/components/HeroSection.tsx`

## File Overview

- Purpose: Hero section for the landing page.
- Why it exists: It explains the product before the user uploads anything.
- Architecture fit: It is the top-of-page marketing and onboarding block.

## Detailed Walkthrough

- Renders decorative tactical lines.
- Shows a status badge.
- Presents the main title and subtitle.
- Maps four feature cards from a static array.

## React / Frontend Concepts

- Pure rendering
- Array mapping

## Engineering Decisions

- The visual style is designed to match the CS2 theme and make the product memorable.

## Dependencies

- React
- Tailwind
